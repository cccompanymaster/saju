# 배경 영상 드롭인 폴더

힉스필드(Higgsfield) 등에서 만든 mp4/webm 루프 영상을 **이 폴더에 그대로 넣으면** 앱에 표시됩니다.
영상이 없으면 기존 그라데이션 포스터가 자동 폴백으로 보여, 언제 넣어도 안전합니다.

## 넣는 법
1. 영상 파일을 `untoon/public/videos/` 에 저장 (예: `reunion.mp4`)
2. `src/data.ts` 의 해당 상품에 파일명만 지정
   ```ts
   {
     id: 'reunion-comeback',
     // ...
     video: 'reunion.mp4',       // 히어로/인트로 배경 (풀스크린, 세로 9:16 권장)
     cardVideo: 'reunion-card.mp4', // (선택) 카드 프리뷰용 짧은 루프 (3:4 권장)
   }
   ```
3. 끝. 히어로 카드·상세 인트로 배경에 켄번스(느린 줌) 효과와 함께 재생됩니다.

## 권장 스펙
- **포맷**: mp4(H.264) 또는 webm. 자동재생 위해 **무음** 필수(코드에서 muted 처리됨)
- **길이**: 4~8초 심리스 루프
- **비율**: 인트로/히어로 배경 = 세로 9:16, 카드 = 3:4
- **용량**: 카드용 1~3MB, 배경용 3~8MB 이하 권장(모바일 로딩)

## 힉스필드 → 앱 연결 경로
- 로컬 파일이 있으면 이 폴더에 바로 복사
- Google Drive에 올려두면, 세션에서 Drive 커넥터로 내려받아 이 폴더에 저장 가능
